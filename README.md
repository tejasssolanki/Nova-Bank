# 🏦 NovaBank

A Java Banking Management System developed using Object-Oriented Programming principles.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Search Account
- View All Accounts
- CSV Storage
- Menu Driven CLI

## Technologies

- Java
- OOP
- Collections
- File Handling
- IntelliJ IDEA
- Git

## Project Structure

```
app
model
repository
service
util
```
